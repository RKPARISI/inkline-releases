Set up a PC in a minute

Download and open

Run InklineSetup.exe. If Windows asks about the download, choose Keep / Run anyway.

Click Install Inkline

Approve the one Windows prompt. Inkline adds its printer and finds the office printers.

Print to Inkline

From Chrome, Word or anything else. Pick a printer in the window that opens, press Print.

Peer to peer out of the box. A PC with a USB printer can share it into Inkline from the same app. Have a server host it for better control: ARIA serves the office printers.
Stays up to date. Installed copies check for new versions every few hours and update themselves. Away from the office? Print later, and it prints when you're back.
On a Mac? The office printers are shared by ARIA with AirPrint-style printing. Open System Settings → Printers & Scanners → Add Printer, and pick the printer listed from ARIA.
